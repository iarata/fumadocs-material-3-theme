Open search with the sidebar button or **⌘ K** on macOS and **Ctrl K** on Windows and Linux.

## Search results

Try searching for **navigation**, **buttons**, or **installation**. Results include a page title, its location in the documentation, and a matching excerpt when available.

## Filter by type

Choose **All results** to browse every match. Choose **Pages** for page destinations or **Sections** to jump directly to a heading within a page.

## Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| **↓** from the search field | Focus the first result |
| **↑** and **↓** in results | Move between results |
| **Enter** | Open the focused result |
| **Escape** | Close search and return to the trigger |

## No matching results

If a search returns no matches, try a shorter phrase or another word. Clear the field to return to the documentation shortcuts.
