## Write it in MDX

```mdx
<Callout type="tip" title="Ready to use">
  Combine **Markdown** with Material components.
</Callout>
<Button variant="tonal" icon="ArrowRight" href="/docs/test/components/forms">
  Explore form controls
</Button>
```

For custom React interactions, import the same controls from `@/components/m3e/mdx` in a `.tsx` component and register it in `src/components/mdx.tsx`.

## Authoring notes

The catalogue covers the components in the [Fumadocs UI component reference](https://www.fumadocs.dev/docs/ui/components), using Material styling and M3E interactions. The existing Fumadocs compiler provides syntax highlighting, generated type tables, and file-tree syntax.

- Use `href` for navigation and `onClick` in a React component for an action. Internal links keep the docs open without a full page reload.
- Buttons default to `size="small"` and a rounded shape. Reserve filled buttons for the main action.
- Icon buttons require a descriptive `label`. Form controls require a visible `label`.
- Keep essential instructions in the page; tooltips provide optional context.
- Interactive examples are backed by M3E custom elements. Their behavior becomes available once the page has hydrated.
