Properties also support `typeDescription`, `typeDescriptionLink`, `deprecated`, `parameters`, and `returns`.

## Generated from TypeScript

This table is generated from `example-types.ts` during MDX compilation. JSDoc descriptions and optional properties stay in sync with the source.

<AutoTypeTable path="./example-types.ts" name="GuideOptions" />

```mdx
<auto-type-table path="./example-types.ts" name="GuideOptions" />
```

The `AutoTypeTable` spelling is supported too. Attributes must be strings, and file paths are relative to the MDX file. Generation happens at build time, so the browser does not load a TypeScript compiler.
