<GraphView />

The map includes page groups and internal document references. Filter by title or URL, zoom with the controls, and select a node to navigate. The expandable list provides the same destinations in a simpler format.

```mdx
<GraphView />
```

A custom graph can be provided with `graph={{ nodes, links }}`. Each node has an `id`, `text`, and `url`; each link has a `source` and `target` node ID.
