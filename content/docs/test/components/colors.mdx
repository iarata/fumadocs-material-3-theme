The default palette pairs a primary blue with a red brand accent. The primary blue marks everything you can act on and where you are: links, primary actions, focus, and the current page. Secondary roles use a quiet slate, tertiary roles add a muted purple, and cool neutral surfaces separate containers from the page. The accent red signs the page (the logo and the overline above each title) and never marks a state. Each container has a paired foreground colour.

## Status colours

  <Badge tone="info">Information</Badge><Badge tone="success">Success</Badge><Badge tone="warning">Warning</Badge><Badge tone="error">Error</Badge>

<Callout type="info">Information uses the primary blue.</Callout>
<Callout type="tip">Tips use the purple tertiary role.</Callout>
<Callout type="success">Success has a distinct green role.</Callout>
<Callout type="warning">Warnings use an amber role.</Callout>
<Callout type="error">Errors use a vermilion role, kept apart from the brand accent by hue and tone.</Callout>

Status colours always accompany a title and an icon, so they never rely on colour alone. All status containers share one tone, so no message is louder than another by accident. The success, warning, and information roles extend the Material palette; they are separate from the standard primary, secondary, tertiary, and error roles.
